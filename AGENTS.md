# AGENTS.md

Project-level agent instructions for DeepSeek Harness. This is the DSH analogue
of `CLAUDE.md`.

## What this repo is

A local DSH test bench: DeepSeek Harness driven by Ox Alpha through OpenRouter,
with skills ported from `claude-code-plugins`.

## Conventions

- Skills live in `.dsh/skills/<name>/SKILL.md` (kebab-case names).
- Ported skills are generated by `scripts/port-cc-skills.sh` — edit the upstream
  skill in `claude-code-plugins` and re-run the port, don't hand-edit the copy.
- Secrets come from the environment (`OPENROUTER_API_KEY`), never from a file
  under version control.

## Ported-skill caveats

Skills written for Claude Code may reference tooling DSH does not have — the
Task tool, CC subagents, CC hooks, `.claude/` paths. Those need a manual pass
before they work here.
